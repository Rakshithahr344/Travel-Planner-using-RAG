# ✈️ Travel planner using RAG

An AI-powered travel planning application that creates personalized travel plans based on the user's destination, budget, number of days, and interests.

The project uses **Retrieval-Augmented Generation (RAG)** to retrieve relevant travel information and **Google Gemini** to generate the final travel plan.

## 🌟 Features

- 📍 Destination-based travel planning
- 💰 Budget-based planning
- 📅 Day-wise itinerary
- 🏨 Hotel suggestions
- 🎒 Packing list
- 💵 Estimated travel cost
- 💡 Travel tips
- 🔎 RAG-based information retrieval
- 🤖 Google Gemini AI
- 🧩 Prompt templates
- 🌐 Streamlit web interface

## 🛠️ Technologies Used

- **Python**
- **Google Gemini**
- **LangChain**
- **FAISS**
- **RAG (Retrieval-Augmented Generation)**
- **Streamlit**
- **Google Gemini Embeddings**
